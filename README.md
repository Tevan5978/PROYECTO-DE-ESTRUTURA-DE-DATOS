# 🕯️ Guía en las Sombras

## Descripción
**Guía en las Sombras** es un simulador de laberintos que utiliza distintos algoritmos de búsqueda y estructuras de datos para encontrar el camino de salida. El proyecto permite visualizar en tiempo real cómo un agente recorre el laberinto usando diferentes estrategias (BFS, DFS, backtracking recursivo), comparando su eficiencia y comportamiento.

## Objetivo
Aplicar de forma práctica los conceptos de complejidad algorítmica, estructuras de datos estáticas y dinámicas (matrices, pilas, colas, recursividad) y teoría de grafos, mediante la resolución visual de laberintos.
